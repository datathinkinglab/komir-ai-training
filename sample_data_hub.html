직접 시도 → 수정 2회 또는 5분 초과 시 복구 → 기능 확인 → 다음 실습. 사용 한도에 걸리면 짝과 생성·검증 역할을 나누거나 강사 결과로 이어갑니다.

  1. 현재 실습 단계의 HTML을 다운로드합니다. 미리보기는 확인용이며 실습은 다운로드한 파일에서 진행합니다.
  2. 기존 정상 파일을 백업한 뒤, 같은 폴더에서 지정된 이름으로 저장합니다. 이름 뒤의 (1), .txt 등을 확인하세요.
  3. 같은 브라우저에서 파일을 열고 기능을 확인합니다. 파일만 옮겨도 저장 기록이 따라가지는 않습니다.
  4. 다른 AI로 전환할 때는 현재 HTML 코드와 다음 기능 요청을 함께 전달합니다.

M7 저장 기능은 브라우저 설정에 따라 제한될 수 있습니다. 차트 단계는 Chart.js를 사용하고, 연결이 안 되면 동일한 집계값의 오프라인 대체 차트를 표시합니다. CSV는 별도로 보관하세요.
